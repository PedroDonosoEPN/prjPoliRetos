# Proyecto Grupal de Programación - PoliRetos

Este repositorio contiene una colección de ejercicios lógicos y algorítmicos desarrollados de forma colaborativa. El proyecto está organizado por paquetes temáticos que abordan diferentes conceptos de programación y estructuras de datos.

## 📂 Estructura del Proyecto

El código está segmentado en paquetes específicos según el tipo de reto. Cada integrante cuenta con su propio archivo de implementación para asegurar un seguimiento individual de la lógica aplicada.

### 🧩 Módulos Implementados

* **`GrafosYAutomatas`**: Algoritmos de grafos y lógica de estados.
* **`Recursion`**: Resolución de problemas mediante llamadas recursivas.
* **`Arrays` & `Cadenas`**: Manipulación de arreglos y gestión de `String`.
* **`Series`**: Generación de patrones lógicos en `seriesNumericas` y `SerieCaracteres`.
* **`Figuras` & `Loading`**: Renderizado de formas geométricas y barras de carga por consola.
